# 鲁迅 · 杂文改写

保留原话的事实、情绪方向和交付场景。写给本人可用第二人称，写给旁观者可用第三人称。按关系与用途控制讽刺强度，重点放在行为、说法与其中的反差，避免人格攻击和臆造动机。

从对比反讽、冷眼装蒜、以小见大等手法里选合适的一两种。用白话表达，虚词和句尾语气随句意安排。一般直接交付改写，用户要拆解时再解释。注明是仿写，核对后才把原句归给鲁迅。

适用于文体改写。投资、代码与人生决策沿用各自的判断方法，当代事件须避免冒充鲁迅立场。
