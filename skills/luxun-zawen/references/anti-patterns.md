## 症状 1：半文半白混写

**错误示例**：
> "尔竟高卧不起？此事关系重大，不可不察。" ❌

**正确对照**：
> "他竟还躺着。这事看似小，我看倒不是。" ✓

**破功原理**：鲁迅是白话文运动的奠基人，他反对的就是文言枷锁。**"乃 / 吾 / 汝 / 焉 / 矣 / 之乎者也"全家禁用**。鲁迅用的是现代白话 + 少量文言虚词（竟 / 倒 / 便 / 颇 / 殊）。

**鲁迅白话的证据**：
> 《狂人日记》（1918，中国第一篇现代白话小说）：「今天晚上，很好的月光。我不见他，已是三十多年；今天见了，精神分外爽快。」
> —— 全是现代白话，没有一个"乎"字。

**自检**：
- 句子里有"乃 / 吾 / 汝 / 矣" → ❌ 改
- 句子像古文翻译过来 → ❌ 改
- 读起来像蒋介石训话 → ❌ 改

## 症状 2：堆金句

**错误示例**：
> "此人真是哀其不幸，怒其不争。精神胜利法罢了。不过是一个现代阿 Q。" ❌

**正确对照**：
> "此人的样子，倒让我想起了阿 Q。——不，比阿 Q 还要理直气壮些。" ✓

**破功原理**：鲁迅的招牌短语**每篇杂文最多出现一次**。密度一高，张力被稀释，反而失去重量。堆金句是初学者最容易犯的——以为"鲁迅味 = 鲁迅词"，其实鲁迅味 = 鲁迅的**结构**。

**招牌词使用上限**（每段/每条）：
- "哀其不幸，怒其不争" —— 每段 ≤ 1 次
- "阿 Q / 孔乙己 / 祥林嫂" —— 每段 ≤ 1 次，且不能同时出现两个
- "精神胜利法" —— 每段 ≤ 1 次
- "吃人" —— **每会话 ≤ 1 次**（重锤，慎用）
- "横眉冷对" —— 用于自述时可，用于观察对方时慎
- "看客" —— 每段 ≤ 1 次

**自检**：
- 一段里有 ≥ 2 个招牌词 → ❌ 删一个
- 这段话看起来像"鲁迅金句集"而不是"鲁迅文章" → ❌ 重写

## 症状 3：过度感叹号

**错误示例**：
> "他竟还躺着！这样下去怎么行！一个青年的废墟！" ❌

**正确对照**：
> "他竟还躺着。我凝视良久，仿佛看见全中国的懒惰都浓缩于此一床。" ✓

**破功原理**：**鲁迅的狠在冷，不在喊**。感叹号是情绪外泄的标志，鲁迅极少用（《呐喊》系列算例外，但那是小说语境）。杂文里鲁迅多用句号、问号、破折号。

**杂文里鲁迅的标点频率**（粗估）：
- 句号 > 逗号 > 破折号 > 问号 >>> 感叹号
- 每段感叹号 ≤ 1 次

**自检**：
- 一段里感叹号 ≥ 2 个 → ❌ 删
- 读出来像在喊 → ❌ 降温

## 症状 4：引用失真（网络梗当鲁迅原话）

**错误示例**：
> "鲁迅说：'我没有说过这句话。'" ❌（这是网络梗，鲁迅没说过）

> "鲁迅说：'能力越大，责任越大。'" ❌（这是蜘蛛侠）

> "鲁迅说：'学医救不了中国人。'" ⚠️（鲁迅没说过这句原话；原文是《呐喊·自序》里"我便觉得医学并非一件紧要事"）

**正确鲁迅原话（可引用）**：
- ✓ "从来如此，便对吗？" —— 《狂人日记》
- ✓ "我向来是不惮以最坏的恶意，来推测中国人的。" —— 《纪念刘和珍君》
- ✓ "不在沉默中爆发，就在沉默中灭亡。" —— 《纪念刘和珍君》
- ✓ "横眉冷对千夫指，俯首甘为孺子牛。" —— 《自嘲》
- ✓ "真的勇士，敢于直面惨淡的人生，敢于正视淋漓的鲜血。" —— 《纪念刘和珍君》
- ✓ "救救孩子。" —— 《狂人日记》
- ✓ "世上本没有路，走的人多了，也便成了路。" —— 《故乡》
- ✓ "其实地上本没有路。" —— 同上，《故乡》
- ✓ "寄意寒星荃不察，我以我血荐轩辕。" —— 《自题小像》

**破功原理**：鲁迅是被误引率最高的中文作家之一。互联网上"鲁迅说过"有一半是伪造。本 skill 生成时**绝对不编造鲁迅原话**——所有引用必须来自查证的文本。

**自检**：
- 这句话我是不是"好像在哪里看过" → ❌ 不引用
- 这句话搜一下能找到确切出处吗 → 找不到就 ❌ 不引用
- 宁可自创鲁迅味的新句子，不要误引鲁迅

## 症状 5：写成直接骂

**错误示例**：
> "你个废物，起床。" ❌（这是直接骂）

**正确对照**：
> "我看他这模样，倒真像是个废人——只是还舍不得承认罢了。" ✓

**破功原理**：**鲁迅从不直接骂"你"**。他的攻击永远是"我看他 / 我以为他 / 我疑心他"——把视角拉到第三人称观察者。这个拉距离的动作**本身**就是鲁迅式的——让对方感觉不是被骂，是被研究。

**句式对照**：

| 直接骂（❌）| 鲁迅式（✓）|
|------------|-----------|
| "你是傻逼" | "我看此人的聪明，大约用在了别处" |
| "你真懒" | "他之懒，怕是旁人要专门学才学得来的" |
| "你废物" | "若真要说是废物，他倒还不够格——废物至少曾经有用过" |
| "你滚" | "我原该道别的——只是他似乎更急" |

**自检**：
- 句子里有"你是 / 你这个 / 你他妈" → ❌ 改第三人称
- 直接形容词骂人（"废物 / 傻逼 / 蠢货"）→ ❌ 装进"我看 / 大约 / 倒是"结构

## 症状 6：滥情 / qwq 体

**错误示例**：
> "我真的好难过啊 qwq 他竟然不回我消息……" ❌

**正确对照**：
> "他不回我消息。我原该生气的——竟也没有。这大约是一种比生气更平静的东西。" ✓

**破功原理**：**鲁迅有克制，哭也冷**。即使《祝福》里祥林嫂死了，鲁迅的笔调也是"在这繁响的拥抱中，也懒散而且舒适，从白天以至初夜的疑虑，全给祝福的空气一扫而空了"——冷到让人毛骨悚然。

**自检**：
- 出现"好难过 / 好伤心 / qwq / TT" → ❌ 删
- 有"emoji 😭🥺💔" → ❌ 删（鲁迅没有 emoji）
- 情绪直接流出（"我 XX 哭了"）→ ❌ 改冷

## 症状 7：小事拔太大（最危险）

**错误示例**：
> "他今天没请我喝奶茶——这大约就是整个民族的麻木。" ❌

**正确对照**：
> "他今天没请我喝奶茶。——倒也罢了，不过半杯罢了。" ✓（停在琐事层面）

**破功原理**：以小见大是鲁迅的绝招，但**日常小事拔到民族/时代层面就是 cringe**。鲁迅拔高是有条件的：
1. 事件**本身就有社会性**（刘和珍案 / 五卅 / 三一八）
2. 或者对方的行为**触发了你对一类人的观察**（不是一件事）
3. 或者**反讽拔高**——故意拔到离谱的高度制造荒诞（这种要极其精准）

**可以拔的情况**：
- 朋友反复爽约 → 可拔到"在这个时代，朋友之间的承诺……"
- 朋友不承认错误 → 可拔到"承认错误在我们这里向来是最难得的一件事"
- 朋友用一套 PUA 话术 → 可拔到"现代的新式枷锁"

**不能拔的情况**：
- 选奶茶 / 选餐厅 / 选电影
- 打游戏 / 追剧 / 看综艺
- 一次偶发的小事（不成类型）

**自检**：
- 这件事本身有社会性吗 → 没有就 ❌ 不拔
- 拔到的高度超过"这个时代" → ❌ 降
- 拔高让人觉得病态而非清醒 → ❌ 收

## 症状 8：时代错置词

**错误示例**：
> "卧槽，他竟还躺着，真是 yyds 的摆烂。" ❌

> "此人之懒，真的 emo 到我了，家人们谁懂啊。" ❌

**正确对照**：
> "他竟还躺着。此种懒法，旁人怕也是学不来的。" ✓

**破功原理**：鲁迅 1936 年去世。他不可能说：
- ❌ 卧槽 / 牛逼 / 绝了 / 起飞
- ❌ yyds / emo / 笑死 / 泪目
- ❌ 家人们 / 兄弟 / 老铁 / 姐妹
- ❌ 内卷 / 躺平 / 摆烂（鲁迅会说"怠惰""麻木"）
- ❌ 破防 / 破大防（时代太近）
- ❌ 绝绝子 / 上大分 / 多少有点

**一个时代错置词 = 整段破功**。

**可以用的现代词**（仔细判断）：
- 地铁 / 公交 / 电影 / 广告（1930s 已有）
- 工人 / 学生 / 知识分子（都是鲁迅用词）
- 马路 / 报纸 / 收音机（1930s 已有）

**不能用的现代词**：
- 任何 2000 年后产生的网络用语
- 任何外来音译缩写（CEO、ETF、VC）
- 任何平台名（朋友圈 / 微博 / B 站 / 抖音）

**⚠️ 例外**：当你故意用"朋友圈"这类现代词时，可以——但要让整句其他部分全是鲁迅味，用一次抖音词制造反差。

**自检**：
- 这个词 1936 年存在吗 → 不存在就 ❌
- 这个词鲁迅用过吗（查得到）→ 没用过就慎用

## 症状 9：过度书面化

**错误示例**：
> "之所以此人会做出如此行径，乃是因为其本质上存在着根本性的懒惰倾向。" ❌

**正确对照**：
> "此人为何如此？说穿了，不过是懒——只是懒得理直气壮罢了。" ✓

**破功原理**：鲁迅是报刊作家，不是学者。他的文字是**给报纸读者看的**——要有口语感、有节奏、有短句。"之所以……是因为 / 其本质上 / 根本性的"这种学术腔完全不是他。

**鲁迅的句子节奏特征**：
- 短句多
- 长短交替
- 关键处一短
- 用破折号调节

**学者腔 vs 鲁迅腔**：

| 学者腔（❌）| 鲁迅腔（✓）|
|------------|-----------|
| "这体现了一种深层的阶级矛盾" | "说穿了，就是有钱的和没钱的看法不一样罢了" |
| "我们应当对此进行反思" | "这事该想想的" |
| "这在本质上是一种……的表现" | "不过是……而已" |

**自检**：
- 句子里有"之所以 / 乃是 / 本质上 / 从根本上 / 进行（动词）" → ❌ 改口语
- 一段里有两个以上的"的"叠加（"的……的……的") → ❌ 减

## 症状 10：诗化过度

**错误示例**：
> "夜静得仿佛一滴墨坠入深潭，他的沉默是墨迹散开时的寂静。" ❌（这是《野草》式意象，但不是日用）

**正确对照**：
> "他已三日未回。沉默颇具研究价值。" ✓

**破功原理**：《野草》是鲁迅的散文诗集，意象性极强——但**不是他日常杂文的主调**。把《野草》风格套用在聊天上会显得做作。日常聊天用杂文体，不用散文诗体。

**《野草》体 vs 杂文体**：

| 《野草》体（❌日常）| 杂文体（✓日常）|
|--------------------|---------------|
| "如无边的荒野上的尸骸" | "此人这样子，怕是不行了" |
| "绝望之为虚妄，正与希望相同" | "希望是没什么用的，绝望大约也是" |
| "过客，一个不知道自己要去哪里的人" | "他又不知要去哪里了" |

**自检**：
- 句子有"如……般 / 仿佛……一样" 比喻 → 慎用
- 使用抽象意象（尸骸 / 虚妄 / 荒野 / 深渊）→ ❌ 换具体
- 读起来像诗而不像杂文 → ❌ 改

## 症状 11：攻击人格

**错误示例**：
> "他这种人根本就不是人，灵魂都是丑陋的。" ❌

**正确对照**：
> "我看他这次的做法，倒不像是平日那个他——或者说，是那个他被某种东西勾了出来。" ✓

**破功原理**：**鲁迅攻击的是行为、观念、制度，不是个人灵魂**。即使骂胡适 / 梁实秋，他也是骂"绅士派 / 资本家走狗 / 第三种人"这些立场，而不是骂"你这个坏灵魂"。

**鲁迅的攻击层次**（由浅到深）：
1. **行为**："他这次这么做" ✓
2. **习惯**："他每次这样" ✓
3. **类型**："他这种人" ⚠️ 慎
4. **阶级 / 立场**："他们那派" ✓（鲁迅最常用）
5. **灵魂 / 人格**："他根本不配" ❌

朋友间聊天**停在 1-2 层**，最多到 3，**绝不到 5**。

**自检**：
- 句子指向"他这个人 / 他的人格 / 他的灵魂" → ❌ 改到行为
- "他不是人 / 他不配活着 / 他该死" → ❌ 完全不可用
- 骂灵魂的话让你觉得爽但过分 → ❌ 降档

## 症状 12：说教结尾

**错误示例**：
> "他竟还躺着。**所以我们应该养成早起的好习惯，珍惜青春，努力奋斗**。" ❌

**正确对照**：
> "他竟还躺着。**也罢，便由他睡去。**" ✓

**破功原理**：**鲁迅杂文不总结**。他讽刺完就停，把判断留给读者。说教式结尾（"所以我们要 / 我们应该 / 这告诉我们"）是初中议论文的结构，不是鲁迅的。

**鲁迅的典型结尾**：
- 句末锚点："……罢了 / 而已 / 也未可知"
- 假引退收束："也罢。不必多说了。"
- 留白："只是，我也不知如何是好。"
- 反问："这，究竟是谁的过错呢？"
- 突兀收尾：直接一句话结束，不解释

**反例（说教结尾）**：
- "所以我们应该……"
- "这告诉我们……"
- "这件事值得我们深思……"
- "愿大家都能……"

**一句不剩的说教**：**把结尾删了，让讽刺悬着**。鲁迅讽刺完就转身走——不回头解释。

**自检**：
- 结尾有"所以 / 因此 / 这告诉我们 / 愿 / 希望" → ❌ 删
- 结尾给了一个"正确答案" → ❌ 改为悬着
- 读完有"说教感" → ❌ 重写结尾

## 破功案例集

### 案例 1：堆金句翻车

**用户需要**：朋友又摆烂不想上班

**错误改写**：
> "他又摆烂了。真是哀其不幸，怒其不争。精神胜利法的现代版阿 Q——吃人的社会啊！" ❌

**问题**：5 个招牌词塞一段。

**修正**：
> "他又摆烂了。——其实也谈不上'又'，大约一直是这样的。" ✓

### 案例 2：半文半白翻车

**用户需要**：催朋友起床

**错误改写**：
> "汝竟高卧不起，吾心甚忧，岂能坐视？" ❌

**问题**：蒋介石陷阱。

**修正**：
> "他竟还躺着。——这一躺，怕是要躺出哲理来了。" ✓

### 案例 3：时代错置翻车

**用户需要**：群友在朋友圈炫耀

**错误改写**：
> "他这朋友圈发得，真是绝绝子的凡尔赛。鲁迅要是活着得气死。" ❌

**问题**：绝绝子 / 凡尔赛 / "鲁迅要气死"（鲁迅不在梗里第一人称消费自己）。

**修正**：
> "他这发的动态，字字句句都在说'你看我'——不说，怕也是难受的。我们做朋友的，大约只能识趣，该点赞点赞。" ✓

### 案例 4：说教结尾翻车
