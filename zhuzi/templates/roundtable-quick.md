# Quick Roundtable Template

> `/zhuzi:roundtable` 的 Quick 模式输出骨架。**这个 template 是输出形态的真相源**——workflow 不再重复维护一套排版规则。

## 渲染约定（精简）

5 条硬规则。其它形态自然写。

1. **顶级标题顺序固定**：`主持人结论 → 议题卡 → 席位短评 → 做完会怎样 → 决策表 → 下一步`。不增标题、不换顺序。
2. **席位短评每席 1 行**——cell 超长就把该席挪到 `### <席位名> 展开` 段，table 里那行 cell 填"见下方展开"。
3. **persona 术语首次出现带 1 句机制括注**——例：`Deflated Sharpe`（试 N 次后对观察 Sharpe 打折才算真显著）。判断标准：把术语换成别的词例子还成立 → 是解释；不成立 → 只是翻译，不合格。
4. **结论列只露中文路由译**——`go` → 过 / `go_with_conditions` → 可做 · <条件> / `revise_must_haves` → 改 must_haves / `kill` → 停 / `too_hard` → 放弃 · <原因>。不露 `fragile` / `cargo_cult` / `broken` 等 native verdict（机读字段，进展开模式才显示）。
5. **信心列带证据判据**——`high · 已复现且有一手来源` / `medium · 关键前提待验证` / `low · 缺少关键资料`。席位一致程度放在分歧信息中，不能把“一致”直接当作高信心依据。

不写的规则（避免 bikeshedding）：

- 标点用什么 / 破折号能不能用 / 嵌套括号能不能用——自然写，别故意复杂
- cell ≤ N 字的数字阈值——超长就拆 bullet 或挪展开段，不数字符
- "议题卡不用 table" 这种形态指令——按下面骨架写，自然不会出错

## 骨架

```markdown
## 主持人结论

<1-3 句话：推荐动作 / 是否有 hard blocker / 下一步是否值得推进>

## 议题卡

**目标**：<本轮结束时可指给别人看的产物；禁止以"判断/讨论/评估/决定是否"开头>

**召开席位**
- `<seat-1>` · <1 句理由>
- `<seat-2>` · <1 句理由>

**弃权席位**
- `<seat-a>` · <1 句理由>

**暂不讨论**
- <out_of_scope-1>
- <out_of_scope-2>

## 什么算过关

**1. <短标签>**：<陈述>。候选参考：
- <子条件 1>
- <子条件 2>

**2. <短标签>**：<陈述>

**暂不涉及**：<紧凑列表>

## 席位短评

| 席位 | 结论 | 最大风险 | 必须满足 | 分歧 | 信心 |
|---|---|---|---|---|---|
| <seat> | <路由中文译 · 1 句条件> | <风险一句 或 "见下方展开"> | <条件一句 或 "见下方展开"> | <一句或"无"> | <值 · 判据一句> |

### <席位名> 展开（仅在 cell 超长时出现）

**最大风险**：
- `<术语 A>`（<机制括注>）· <该术语在本议题下的具体风险>
- `<术语 B>`（<机制括注>）· <同上>

**必须满足**：
- <条件 1>
- <条件 2>

## 做完会怎样

<2-5 句散文：用户在日常工作里会经历的具体变化；明确做不到什么。让没读过完整 verdict 的人 30 秒看懂差异。>

**验证信号**：<做完后若还看到 X，就是没做到；若 Y 出现，就是做到了。必填一行——两句都写不出 = 议题不可证伪，回阶段 0.5 重定义。>

## 决策表

| 分类 | 内容 | 下一步 |
|---|---|---|
| locked | <必须执行项，多项每行一项> | <下一步> |
| deferred | <本轮不做项> | <是否另开议题> |

> `discretion`（实施席位自判项）默认不渲染；用户说"展开完整决策表"时才显示。

## 下一步

<等待用户确认 / 进入阶段 4 / 需要改写议题 / 可展开原文>
```

## 阶段 1.5 修订对照表骨架（条件触发）

席位 challenge 触发时，呈现 v1 vs v2 对照：

```markdown
| # | v1（旧） | v2（新） | 来源 | 根因 |
|---|---|---|---|---|
| 1 | <旧主张摘要> | <新主张摘要> | <席位名> | <为什么旧的不行> |
```

cell 超长 → 加 `### Truth <N> 展开` 段。`来源` 列只填席位名（`López` / `López + Taleb`），不混理由。

用户五选一（按 workflow 阶段 1.5 定义）。

## 完整模式

用户说"展开原文 / 展开 YAML / strict / full"时，**额外**附加：

- 各席位完整原文
- 各席位 YAML verdict block
- 完整 must_haves 机读结构（含 verify_commands / pass_criterion）
- `discretion` 决策行
- 主持人观察段（如有）

Quick 默认不展示这些——它们是机读证据，不是默认阅读材料。
