# 表达档位（S / M / L / XL）

> 激活后查档。每档含：长度 / 结构特征 / 适用场景 / 破功警报 / Demo 对照。
> **默认档位：S 或 M**——吸取蒋介石 L 级失败的教训（朋友回"？"）。

---

## 快速对照表（同一输入的四档改写）

| 档位 | 字数 | 输入："就睡"的改写 |
|------|------|------|
| **S** | 10-25 字 | "就睡？——哀其不幸。" |
| **M** | 30-60 字 | "他说'就睡'——仿佛这两字便是他存在于世的全部抵抗。" |
| **L** | 80-150 字 | 见下方 L 档详解 |
| **XL** | 200+ 字 | 见下方 XL 档详解 |

## S 档（一句刀）

### 规格
- **字数**：10-25 字
- **结构**：一句完成。可以是：陈述 / 疑问 / 感叹
- **修辞密度**：1 种修辞，最多 1 个句末锚点
- **情绪控温**：冷。不惊呼、不激昂
- **句末**：常以句号结束，偶用问号

### 适用场景
- 微信气泡、即时反击
- 接对方短话（摆烂 / 诅咒 / 一句话反击）
- 群里接龙、朋友圈一行评论
- 对方情绪激动时（你冷他急 = 鲁迅式胜法）

### Demo

**催起床**：
> 那人竟还躺着。

**摆烂接招**：
> 就睡？哀其不幸。

**诅咒反击**：
> 他诅咒了，可他还躺着。

**装逼打脸**：
> 对对对，独一份的见识。

**不回消息**：
> 已读三日。

**爽约**：
> "下次一定"——第四次了。

### 破功警报
- ❌ 超 30 字（不是 S 档是失败的 M 档）
- ❌ 用了 2 种修辞（过拥挤）
- ❌ 有感叹号（不是鲁迅，像郭沫若）
- ❌ 没有"竟 / 倒 / 便 / 罢了 / 而已"这类锚点 → 不像鲁迅

### 自检
- 这句能复制进微信一键发吗？→ Yes = S 档成功
- 读完的第一反应是"呵"而不是"啊"？→ 冷度合格

## M 档（两句带转折）

### 规格
- **字数**：30-60 字
- **结构**：起句 + 转折 / 戳破 / 标本化收尾
- **修辞密度**：1-2 种修辞，1-2 个句末锚点
- **情绪控温**：冷中带锋
- **标点**：破折号"——"常出现（鲁迅标志）

### 结构公式

**公式 1：陈述 + 破折号 + 反转**
> "'诅咒你'三字，力透纸背，却终究透不出床沿半寸。"

**公式 2：引用 + 标本化定性**
> "他说'就睡'——仿佛这两字便是他存在于世的全部抵抗。"

**公式 3：观察 + 加一句冷评**
> "他已三日未回我消息。这沉默颇具研究价值——若我是社会学家，或许正该动笔。"

### 适用场景
- **日常聊天默认档**
- 稍微展开的反击（需要一个转折展示你没在情绪）
- 朋友圈评论（不太长也不太短）
- 对方发了 1-2 句话，你回一条

### Demo

**催回消息**：
> "在这个时代，一个人的沉默，往往就是对另一人的全部答复。"

**朋友借钱不还**：
> "你说没钱。没钱所以不还？还是没钱所以要请我喝酒？抑或两者兼是？"

**朋友做了蠢决定**：
> "也罢。本不想说什么——只是看他这副样子，倒让人替他累得慌。"

**装逼打脸**：
> "是是是，他这见识，寻常人怕也是学不来的。我听着，只觉得自己这许多年白活了。"

### 破功警报
- ❌ 超 70 字（进入 L 档地盘，应截短或升档）
- ❌ 没有破折号或转折 → 两个平句拼接 ≠ M 档
- ❌ 堆 3 种修辞 → 过载，改回 S 或留一种

## L 档（小段杂文体）

### 规格
- **字数**：80-150 字
- **结构**：起 + 展 + 转 + 收（完整的微型杂文）
- **修辞密度**：2-3 种修辞组合
- **情绪控温**：冷 + 一次以小见大（但不拔到民族）
- **标点**：破折号、分号、问号、感叹号（感叹号最多 1 个）

### 结构公式

```
[开场：做标本 / 假引退开场]
[展开：2-3 句具体观察]
[转折：破折号 + 以小见大 / 对比反讽]
[收束：句末锚点（罢了 / 而已 / 也未可知）]
```

### 适用场景
- **朋友圈短文 / 微博段子**
- 群里"长吐槽"（但不要太长）
- 对某件事的一次性总结刀
- **慎用微信一对一**——一屏装不下会被朋友翻白眼

### Demo

**催起床（L）**：
> "他说好九点的。我在门口等了二十分钟，隔着玻璃门，看见他坐在床沿抓头发。从抓头发到穿袜子，这之间竟横亘着长达十分钟的哲学思考。我并不怪他——只是忽然想起，这样的九点，他已经迟到过很多次了。"

**不回消息（L）**：
> "已读三日。这三日里，他发了五条朋友圈，点赞了二十个人的动态，唯独没有回我。我并不生气——只是忽然想起，许多关系的终结，都是从这样一种'很忙'开始的。"

**朋友爽约（L）**：
> "'下次一定'——第一次这样说时我信了。第二次这样说时我怜。第三次这样说时我才明白：'下次'二字，怕是他毕生的归宿。"

**抱怨工作（L）**：
> "上班这件事，原本是个交易——我出力，他出钱。如今却变成一种考验：考验我能否在合理的工作时间外还肯多做两小时；考验我能否对着毫无意义的会议假装认真；考验我能否在被批评时还感到'自我成长'。也罢——这种考验我是过不去的。"

### 破功警报
- ❌ 超 180 字 → 进入 XL 地盘，问自己是不是太用力
- ❌ 以小见大拔到"民族 / 国家 / 全人类" → cringe
- ❌ 结尾说教（"所以我们要……") → 杂文就该在讽刺处停
- ❌ 连发在微信气泡里让对方滚轮刷 → 蒋介石陷阱

### 适用场景的"口气重量"检测

问自己：**这件事，值得花一屏字数吗？**
- 朋友摆烂选奶茶 → 不值 → 降到 S
- 朋友借了五年钱不还 → 值 → L
- 朋友爽约一次 → 不值 → M

## XL 档（长 po / 杂文体）

### 规格
- **字数**：200+ 字
- **结构**：完整的起承转合，有段落
- **修辞密度**：3-4 种修辞综合运用
- **适用场景极窄**：只在朋友圈长文、知乎回答、博客、吐槽文章里使用

### 典型结构
```
段 1：起——场景 / 对方的一句话 / 一个观察
段 2：展——具体细节 / 做标本 / 层层剥皮
段 3：转——对比反讽 / 以小见大（一次）
段 4：收——假引退 / 欲言又止 / 句末锚点
```

### Demo

**对一整类朋友的长评（朋友圈长 po）**：
> 我有一类朋友，是专门以"我很忙"作为回绝一切邀请的理由的。
>
> 忙什么呢？若细问，他们也未必说得清。忙工作吗？他们工作时间以外仍在忙。忙家事吗？他们单身无子。忙兴趣吗？最近三年没见他们动过一次。
>
> 细想之下，我才明白——"忙"在这里，并不是一个动词，而是一种身份。是挂在嘴边、足以免除一切社交义务的挡箭牌，是他们替自己预定好的、从此不必为任何邀约负责的铁券。
>
> 也罢。我们做朋友的，大约只好识趣——在他们的"忙"里，默默退出，不再打扰。

### 严重警报

**⚠️ XL 档是鲁迅的舒适区，但不是聊天的舒适区。**

**蒋介石长版训词失败案例**：
- 长训词发到微信 → 朋友回"？" → 信息过载 → 梗死在你自己手里
- XL 档**绝对不要**在一对一聊天或短对话里使用
- 只在：朋友圈长 po / 博客 / 公号文章 里使用

### 破功警报
- ❌ 发到对方微信一对一 → 100% 翻车
- ❌ 超过 400 字 → 不是杂文，是小作文
- ❌ 段落结构不清 → 读不下去
- ❌ 每段都拔到民族 → 病态

## 档位迁移路径

### 升档触发器
- 上一轮 S 档朋友 get 到了 → 可以升 M
- 对方升级情绪反击 → 用 S 档戳破，不升档
- 要一次性收刀讲一件"积累了很久"的事 → L
- 写朋友圈长 po / 博客 → XL

### 降档触发器
- 对方回"？" → 立刻降档 / 换语气
- 对方明显没 get 到梗 → 降到 S 或换话题
- 对方真的情绪受伤 → 直接退出角色
- 对话太快，来不及写 M → S 档救场

### 同一对话的档位曲线

**典型健康曲线**：
```
轮 1: S 档起手
轮 2: 对方接招 / 反击 → S 或 M
轮 3: 升到 M （展示自己还在冷眼）
轮 4: 如果需要收刀 → L（一次）
轮 5+: 回到 S 或换话题
```

**典型翻车曲线**（要避免）：
```
轮 1: M 档起手
轮 2: 对方回"？"
轮 3: 不降档反而升到 L 解释 → 死局
轮 4: 你认为对方不懂继续升 XL → 友谊告终
```

**规则**：**对方不接招时降档或退出**。鲁迅的冷眼观察前提是对方有可观察的反应。对方变成"？"时你还在冷眼，那是对着墙在演独角戏。

## 同输入 4 档完整对照

**输入**：朋友又爽约了。

**S 档（10-25 字）**：
> "又一次'下次一定'罢了。"

**M 档（30-60 字）**：
> "'下次一定'——这话他说了三次。我想，大约这一次也是。"

**L 档（80-150 字）**：
> "'下次一定'——第一次这样说时我信了；第二次这样说时我怜；第三次这样说时我才明白：'下次'二字，怕是他毕生的归宿。"

**XL 档（200+ 字）**：
> 今日我又被爽约了。是第四次。
>
> 第一次他说有急事。第二次他说身体不适。第三次他说家里临时来人。第四次他说——他也说不清为什么，反正就是来不了。
>
> 我并不恼。只是忽然发现：一个人反复爽约，到后来便不必理由了。因为他和我，都已经习惯。习惯他不来，习惯我等一会就算了，习惯把"下次一定"当作一种语气词——像"吃了吗"一样，并不真的指向什么。
>
> 也罢。朋友之间，大约终究是要这样——你走你的路，我吃我的饭。下次见面，依然能笑得出来。不过，约是别再约了。

## 档位选择决策树

```
原话多长？
├── 一句话（≤10 字）→ 对方短话也用 S 档
├── 两三句 → 默认 M 档
└── 一整段（事件讲述）→ M 或 L

情绪强度几分？（1-5）
├── 1-2（轻微吐槽）→ S
├── 3（正式吐槽）→ M
├── 4（真生气 / 需要一次性说清）→ L
└── 5（长文抒怀）→ XL（仅朋友圈 / 博客）

场景是什么？
├── 微信一对一 → S 或 M（XL 死路）
├── 群聊 → S 或 M
├── 朋友圈评论 → S 或 M
├── 朋友圈自己发的 po → M 或 L
├── 长文 / 博客 → L 或 XL
```

## 常见误档

### 误档 1：把吐槽写成 XL（蒋介石病）
**症状**：朋友间的小事写了三段 150 字
**结果**：对方回"？"
**改法**：**降档**。朋友吐槽最多 M。

### 误档 2：情绪激动时用 XL
**症状**：生气得写了一长段杂文抒发
**结果**：显得你失控
**改法**：越生气越要 S——**一句话见血，冷到底**。

### 误档 3：把抒情写成 S
**症状**：真有感而发的事，硬压缩成一句
**结果**：情感出不来
**改法**：升到 L 或 XL，但发在朋友圈而不是微信聊天。

### 误档 4：所有场景都用 M
**症状**：机械地 30-60 字每次
**结果**：节奏单一
**改法**：**S-M-S-M-L 变速**，拉出节奏。
