## 场景 1：催起床 / 催行动

**触发信号**：对方约好要起 / 要动 / 要去，结果没动静；或你需要推一把。

**推荐修辞**：做标本（把"还躺着"当样本）+ 对比反讽（比如嘴上说要起身体不动）

**S 档（10-25 字）**：
> 那人竟还躺着。

> 他说要起。这话说了四遍了。

**M 档（30-60 字）**：
> 那人竟还躺着——我凝视良久，仿佛看见全中国的懒惰都浓缩于此一床。

> 他嘴上说起，手上摸枕头；嘴上说走，腿上还盖着被。此种分裂，值得研究。

**L 档（80-150 字，朋友圈用）**：
> 他说好九点的。我在门口等了二十分钟，隔着玻璃门，看见他坐在床沿抓头发。从抓头发到穿袜子，这之间竟横亘着长达十分钟的哲学思考。我并不怪他——只是忽然想起，这样的九点，他已经迟到过很多次了。

**误用**：
- ❌ 对方是病人 / 真的累了 → 不要用，换共情腔
- ❌ 非朋友关系 → 慎用（容易被当真生气）

## 场景 2：摆烂接招（"就睡" / "懒得管" / "不想去"）

**触发信号**：对方用极短的摆烂话头把球踢回来。

**推荐修辞**：对比反讽（戳破"嘴硬但物理上还是什么没做"）+ 做标本

**S 档**：
> 就睡？——哀其不幸。

> 他说"不去"——斩钉截铁，斩钉截铁到连理由也懒得编一个。

**M 档**：
> 他说"就睡"——仿佛这两字便是他存在于世的全部抵抗。

> "不想去"——三字里藏着三种不同的懒：身不动 / 心不愿 / 脑不转。

**多轮范式**：

```
你：[催促原话]
对方：就睡
你：[S 档]就睡？——哀其不幸。
对方：[可能反击"诅咒你" / 继续摆烂 / 笑]
你：[见场景 3 接招]
```

## 场景 3：诅咒反击（"诅咒你" / "去死" / "你完蛋了"）

**触发信号**：对方被你的上一句扎到，用情绪化反击。**说明你前一句赢了**——继续施压。

**推荐修辞**：对比反讽——**戳破他的情绪 vs 物理状态**。不回击情绪，而是指出"你情绪这么大，但你什么都没做"。

**S 档**：
> "诅咒你"三字，力透纸背，却终究透不出床沿半寸。

> 他诅咒了，可他还躺着。

**M 档**：
> 诅咒便诅咒罢。只是诅咒完了——他还得起床，还得洗脸，还得去上班。诅咒并不能替他做这些事。

**为什么这招管用**：
- 对方情绪化 = 他已经被扎中
- 你不接情绪 = 他无法升级对抗
- 戳破物理状态 = 把话题拉回起点（起床这件事还没解决）
- 冷静 vs 激动的反差 = 鲁迅最擅长的赢法

**误用**：
- ❌ 对方的"诅咒你"是真生气（不是玩梗）→ 立刻停，换正常语气
- ❌ 对方情绪脆弱 → 换共情

## 场景 4：爽约追讨 / "下次一定"

**触发信号**：对方答应过的事没做 / 反复说"下次"。

**推荐修辞**：祥林嫂式絮叨（把"下次一定"这句话反复引用）+ 层层剥皮

**M 档**：
> "下次一定"——上次你说下次一定，上上次你说下次一定。我渐渐明白：你说的"下次"，大约从来不是那个"下次"。

> 他约了三次，爽约三次，每次都说下次一定。我竟有些好奇：这"下次"究竟是在哪一天？

**L 档（祥林嫂式）**：
> "下次一定"——第一次这样说时我信了。第二次这样说时我怜。第三次这样说时我才明白："下次"二字，怕是他毕生的归宿。

**原型引用**：祥林嫂反复说"我真傻，真的"——这种反复本身就是做标本的极致形态。

## 场景 5：借钱不还

**触发信号**：借出去的钱迟迟不还 / 对方主动转移话题。

**推荐修辞**：层层剥皮——用递进诘问剥到对方逻辑漏洞。

**M 档**：
> 你说没钱。没钱所以不还？还是没钱所以要请我喝酒？抑或两者兼是？

> "等我发工资"——上月发工资时你买了新手机。上上月发工资时你换了鞋。这月要发工资了——你会先想起谁？

**L 档**：
> 借钱这件事，我原是不计较的。只是——当我看到他朋友圈里又一顿火锅、又一次旅行、又一只包——我总忍不住去想：这些东西里头，有多少是我的？

**警报**：
- ❌ 金额小（< 50 元）别用这套，显得小家子气
- ❌ 对方真的困难 → 换假引退共情腔

## 场景 6：装逼打脸 / 好为人师

**触发信号**：朋友在炫耀 / 装懂 / 教你做人。

**推荐修辞**：冷眼装蒜——**假装彻底认同，捧到最高再不动声色放下**。

**S 档**：
> 对对对，独一份的见识。

> 听君一席话。

**M 档**：
> 是是是，他这见识，寻常人怕也是学不来的。我听着，只觉得自己这许多年白活了。

> 他说得是。我果然是错的——连"认错"这件事，也错得不够彻底。

**L 档**：
> 听君一席话，胜读十年书。——只是这十年我原也读过，读来读去，竟和他说的有些不一样。不知是哪本读错了，还是哪本没读到。也罢。

**搭配**：+ 假引退（"本不该打断他兴致") 最狠。

## 场景 7：朋友不回消息

**触发信号**：消息已读 / 未读很久 / 沉默。

**推荐修辞**：以小见大（节制）+ 做标本

**S 档**：
> 沉默。

> 他已三日未回。

**M 档**：
> 他已三日未回我消息。这沉默颇具研究价值——若我是社会学家，或许正该动笔。

> 在这个时代，一个人的沉默，往往就是对另一人的全部答复。

**L 档（朋友圈抱怨）**：
> 已读三日。这三日里，他发了五条朋友圈，点赞了二十个人的动态，唯独没有回我。我并不生气——只是忽然想起，许多关系的终结，都是从这样一种"很忙"开始的。

**警报**：
- ❌ 对方真的有急事 → 立刻降档道歉
- ❌ 发给对方本人（不是吐槽）→ 换成直球"在吗"，鲁迅腔只适合第三方吐槽或心里 OS

## 场景 8：抱怨工作 / 老板

**触发信号**：你对朋友吐槽工作 / 领导 / 同事。

**推荐修辞**：层层剥皮（剥到荒谬的内核）+ 假引退（"也罢，不说了"）

**M 档**：
> 老板说要"结果导向"。什么结果？做出来了不算？做出来还要他满意？满意到什么程度？——每次我快要弄明白的时候，标准就又变了。

> "996 是福报"——这话若从老板嘴里说出，倒也不奇怪。奇怪的是，有人听着听着，真就信了。

**L 档**：
> 上班这件事，原本是个交易——我出力，他出钱。如今却变成一种考验：考验我能否在合理的工作时间外，还肯多做两小时；考验我能否对着毫无意义的会议假装认真；考验我能否在被批评时还感到"自我成长"。也罢——这种考验我是过不去的。

## 场景 9：朋友反复卖惨（祥林嫂式）

**触发信号**：朋友反反复复说同一件事 / 同一个创伤。

**推荐修辞**：做标本（把反复行为本身当样本）+ 假引退（"也罢"）

**M 档**：
> 他又说起那件事了。昨日说过，前日说过，再前日也说过。也罢，谁都有那么一桩说不完的事——只是听的人，也该有说不完的耐心才行。

**⚠️ 严重警报**：
- ❌ 朋友真的抑郁 / 创伤 → **绝对不要用这招**，换共情
- ❌ 面对面说出来 → 换成温和的"要不要换个话题"
- 此招**只适合心里 OS / 和第三方吐槽**，不对当事人说

## 场景 10：朋友 PUA 自己

**触发信号**：朋友反复说"都是我的错 / 我就是废物 / 我配不上"。

**推荐修辞**：冷眼装蒜（假装同意，让他听见这句话有多荒谬）

**M 档**：
> 他说得是。他果然处处不对。——想来连"处处不对"这件事，也是他自己的过错罢。

> "我就是废物"——他说得斩钉截铁。斩钉截铁到我几乎要信了——但凡说得再诚恳一点。

**为什么管用**：把他的话复述一遍，让他自己听到其中的荒谬。

**警报**：
- ❌ 对方真的抑郁 → 绝对不要用，换正经关心
- 此招只对**习惯性自贬但其实不是抑郁**的朋友有效

---

## 场景 11：朋友做蠢决定

**触发信号**：朋友要去做一件你判断会失败的事。

**推荐修辞**：假引退 + 冷眼装蒜

**M 档**：
> 也罢。本不想说什么——只是看他这副样子，倒让人替他累得慌。

> 他定了主意，谁也拦不住。我原该恭喜他——只是我记得上次他这样说时，也是这么一副脸色。

**L 档**：
> 本以为不必多言。既然问起了，便直说罢——这一步若走得成，自然是好的；若走不成，也不必来找我。朋友之间的话，我大致只能说到这里了。

## 场景 12：群友在装逼 / 朋友圈炫耀

**触发信号**：群里有人卖弄 / 朋友圈凡尔赛。

**推荐修辞**：冷眼装蒜 + 轻以小见大（一次）

**M 档**：
> 听君一席话，胜读十年书。——只是这十年我原也读过，读来读去，竟和他说的有些不一样，不知是哪本读错了。

**L 档（朋友圈回复）**：
> 羡慕。羡慕得都想把这种"随手一提就能让人羡慕"的本事学一学——可惜天资所限，学不来。

## 多轮对话的升档策略

**规则**：
- **轮 1**：S 档起手（试水）
- **对方如果 get 到 → 继续 M 档**
- **对方如果反击 → S 档戳破**
- **对方如果升级 → L 档一次性收刀**
- **对方如果懵 / 不接招 → 降档或换正常语气**

**禁忌**：
- ❌ 不要连续 3 轮都用同一种修辞
- ❌ 不要越打越长（蒋介石式螺旋）
- ❌ 不要在对方明显不接招时继续装

## 实战记录（本 skill 诞生对话）

**原始对话**：
```
你：叼毛！还不起床
对方：就睡
你：（选择鲁迅 S 档）"就睡？——我看这两字之下，埋着一个青年的精神废墟。哀其不幸。"
对方：诅咒你（= 被扎到，反击）
你：（选择鲁迅 M 档）"'诅咒你'三字，力透纸背，却终究透不出床沿半寸。"
```

**数据点**：
- **蒋介石 L 档训词** → 对方回"？"（信息过载失败）
- **曹操 S 档** → 对方回"就睡"（接上但摆烂）
- **鲁迅 S 档**（做标本）→ 对方回"诅咒你"（被扎到反击）✓
- **鲁迅 M 档**（对比反讽）→ 预期进一步扎穿

**结论**：S→M 渐进升档、不同修辞轮换、档位与场景匹配，是鲁迅腔的正确用法。长≠狠，冷眼 + 对比 > 训斥 + 排比。

## 输出前的场景自检

每次改写前问自己：

1. **这是什么场景？**（查表）
2. **对方是什么状态？**（新起 / 接招 / 情绪化 / 摆烂 / 装逼）
3. **这把刀该多长？**（默认 S-M，只在需要一次收刀时上 L）
4. **上一句我用了什么修辞？**（下一句换一种）
5. **扎完了吗？**（对方被扎穿了就停，不要继续打死马）
