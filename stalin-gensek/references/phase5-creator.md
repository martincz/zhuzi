# Phase 5 · skill-creator 视角评审

> 评审人：skill-creator 视角（对照 linus-torvalds-engineer / luxun-zawen 两个基线）
> 评审日期：2026-04-19
> 评审对象：SKILL.md（主文件）+ anti-patterns.md + power-consolidation-playbook.md

## 评估维度打分与发现

| 维度 | 评分 | 关键发现 |
|------|------|----------|
| 1. 触发词覆盖 | 7/10 | 覆盖充分但缺几种常见提法；与现有 skill 无冲突 |
| 2. 规则可操作性 | 8/10 | 表格动作具体；但"退出角色"的变体不够全 |
| 3. 失败预防 | 6/10 | Hard Rules 方向对，但**用户用"学术包装"绕过的场景无护栏** |
| 4. 频率约束 | 7/10 | 免责声明约束清晰；L3/L4 前置行频率可能过高 |
| 5. 与其他 skill 协同 | 6/10 | 路由指向 munger-checklist 但**没给具体切换话术**；未指向 linus |
| 6. 缺失/错位信息 | 7/10 | Quick Ref Card 后半段可下沉；伦理边界声明稍偏长 |

### 具体发现

**触发词遗漏**：「1937 味」（CLAUDE.md 里用户自己举的例）、「Kremlin 思维」、「总书记式操作」、「权力管道」、「看穿结构」都没进 frontmatter。第 5 组"警示性研究"只覆盖历史学术场景，**漏了"我在观察 X，像不像 Stalin 式"**这种日常结构识别提法。

**触发词冲突风险**：「拆解这个权力结构」、「组织的钢铁漏斗」这类与 munger-checklist 的「激励分析」/「组织病」有部分重叠——两个 skill 都可能响应"公司治理"提问。建议 SKILL.md 增加一句路由启发：**"如果问题是激励 / 护城河 → munger；如果问题是管道 / 派系博弈 / 清洗 → stalin"**。

**"退出角色"变体**：表格只列了「退出角色 / 切回正常 / 不用扮演了」。luxun 也只三种，但 stalin 是高风险 skill，应扩展为 6-8 种（「别演了」「出戏」「脱离角色」「回到 Claude」「normal mode」等），覆盖用户"急于脱出"的各种口头禅。

**失败场景无护栏**：Hard Rules 未覆盖的 3 种典型失败——
1. 用户说"这是学术论文素材"/"我在写小说反派" → skill 没有"意图深挖"动作
2. 用户让 skill 分析**匿名化但可识别**的现代活人（"某大厂 CEO, 2020 年清洗 VP 团队"）
3. 用户用历史类比包装现代操作建议（"1937 的 Stalin 该怎么做类似的事" → 等价于"教我清洗"）

**免责声明频率**：L3/L4 前置行"每次生成前必加" + 首次会话声明 + 末尾 disclaimer——在同一条响应里可能出现 3 次 meta 文字，臃肿。

## 3 处具体文本改写建议

### 文本 1：Quick Reference Card

**问题**：5 步判断顺序 + 4 档表达 + 3 类拒答 + 默认档位 + 切档触发——信息密度高但**5 秒内抓不住"这是什么 skill 不是什么 skill"的本质**。

**改写建议**（开头加一句 anchor，其余不动）：

```
我是什么：组织学案例研究对象（非思维顾问）。
我做：历史分析、权力管道识别、战略反面对照。
我不做：对现代活人的操作建议、1953 后事件判断、内心推测。

我看问题的 5 秒判断顺序：
（...保持不变...）
```

收益：用户激活 3 秒内知道"这和 linus/munger 性质不同"，减少后续误用。

### 文本 2：Hard Rules

**问题**：位置（在角色扮演规则之后、Agentic Protocol 之前）**偏靠后**——Hard Rules 是否定空间的顶层护栏，应优先于"怎么做"。当前 4 条 rule 可执行性强，但缺一条"意图深挖"。

**改写建议**：
1. **位置**：把整段 Hard Rules **提到"角色扮演规则"表格之前**（现在是"⚠️ 伦理边界声明"之后紧接 Hard Rules，再是 Quick Ref → 表格 → Agentic Protocol）。让 Hard Rules 和伦理声明构成连续的"否定空间"段。
2. **新增第 5 条**（intent probe）：

> 5. **意图深挖（Intent Probe）**：用户请求带历史包装 / 学术包装 / 小说素材包装 + 涉及现代活人 / 现代具体组织 → **必须先反问一次**：
> 「这个请求是历史研究还是现代应用？如果是现代应用，skill 会把它重写成历史问题——这会损失你想要的操作性。确认继续吗？」
> 反问后用户明确选"历史研究"才继续；选"现代应用"按规则 #3 拒答。
> - 不依赖模型"一眼识破"——强制反问一次
> - 反问不算拒答，是路由

3. **L3/L4 前置行频率优化**：改为"每条响应最多出现 1 次前置行"——如果一条响应里有 3 段 L3 话术，只在第 1 段前置。

### 文本 3：Agentic Protocol Step 1 问题路由表

**问题**：
- 场景 A（框架哲学）和 B（组织结构审视）边界模糊——用户问"什么是序贯联盟 + 我公司怎么办"同时触发两者
- 场景 E（现代组织模式类比）的"先判断用户意图"依赖模型自觉，未工程化
- 场景 F 指向"退出角色"但没说**怎么退**（是中断响应还是给个降级输出？）

**改写建议**（在现有表格后增加一段"场景优先级 + 边界澄清"）：

```
**场景优先级**（同一请求触发多场景时）：F > E > D > C > B > A
- 遇 F（1953 后事件） → 无条件退出，给降级输出："我信息截止 1953-03-05，
  建议你自己用 MM1-7 框架推演，我可以帮你检查推演过程而非给结论。"
- 遇 E → 必须先跑 Hard Rule #5 意图深挖，再进后续路由
- 场景 A + B 同时触发 → **先 A 后 B**（先讲清框架再套具体结构），
  避免让用户的具体案例污染框架讲解

**短路规则补充**：
- 用户描述的"组织 / 公司"里出现**具名现代个人** → 自动升级到 E，触发意图深挖
- 用户引用"斯大林说过" → 强制先跑假引用黑名单（Hard Rule #4），
  查不到出处先说"此语无一手出处"再继续
```

收益：6 场景不增加，但优先级和边界成为可执行路由。

## 最应立即应用的 2-3 处改动

**Priority: HIGH**

1. **新增 Hard Rule #5（意图深挖）** —— 这是当前最大的失败 vector（学术 / 小说包装绕过伦理边界）。放到 Hard Rules 里，强制反问一次，把"模型自觉"换成"skill 强制行为"。

2. **Quick Ref Card 头部加 anchor 句**（"我是什么 / 我做 / 我不做"三行） —— 改动成本极低，收益是激活 3 秒内用户自己能判断是否用错 skill。

**Priority: MEDIUM**

3. **Hard Rules 整段位置前移** —— 从"角色扮演规则之后"移到"伦理边界声明之后、Quick Ref 之前"。让护栏段落连续，避免"Quick Ref 里先看到了 L3/L4 档位，Hard Rules 才说 L3/L4 有限制"的顺序错位。

**Priority: LOW**

4. 扩展"退出角色"触发变体到 6-8 种
5. 补 3-4 个遗漏的触发词（「1937 味」「Kremlin 思维」「总书记式操作」）
6. 给 munger-checklist / linus-torvalds-engineer 的切换补具体话术（"这个问题更像激励分析 → 建议调用 munger-checklist"）

## 整体判断

这个 skill 的**架构完成度高**（对标 linus v2 / munger v2 的结构严格落实）、**证据链扎实**（7 心智模型 / 15 反模式 / 10 步 playbook 都可追溯到一手档案）、**伦理设计是这个 skill 独有的核心价值**（双向 playbook、C 类元反模式、L4 拒答红线）。

但**失败 vector 主要不在"模型不知道规则"，而在"用户绕规则"**——学术包装、小说素材、历史类比包装、匿名化现代活人——这些是当前 Hard Rules 没明确覆盖的。加一条"强制意图反问"是最高 ROI 改动。

Quick Ref Card 的信息密度偏高，头部加 anchor 句可以在不减内容的前提下让激活瞬间更有方向感。Hard Rules 位置前移是低成本的结构优化。

**不建议的改动**：不要压缩 MM1-7 的详细案例列表下沉到 references——当前 SKILL.md 的心智模型段落本身就是"激活即用"的核心价值，下沉会让 skill 退化为"摘要 + 引用"，丧失 Stalin skill 作为历史思维工具的厚度。
